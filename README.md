## Una pequeña carta de presentación

Gracias por pasar por acá. Soy desarrollador de software y mi especialidad es **Adobe Experience Manager Cloud**, con un pie en Java y otro en el frontend. Disfruto tanto diseñar un componente reutilizable como pulir esos detalles que hacen que una página cargue mejor, sea accesible y resulte agradable de usar.

Mi recorrido me llevó a colaborar con equipos internacionales, desarrollar productos para distintas marcas y acompañar a otros desarrolladores. En ese camino aprendí a valorar el código que se entiende, la documentación que ayuda y las conversaciones que destraban problemas.

Este espacio reúne parte de ese recorrido: proyectos públicos, herramientas que nacieron de necesidades concretas y apuntes para seguir aprendiendo. Si algo de lo que ves te sirve, ya valió la pena compartirlo.
